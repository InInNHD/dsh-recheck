# Security / 安全反馈

For a vulnerability, use [private vulnerability reporting](https://github.com/InInNHD/dsh-recheck/security/advisories/new). Do not attach API keys, authentication URLs, browser storage state or private project data to public issues.

发现漏洞时，使用已启用的[私密漏洞报告入口](https://github.com/InInNHD/dsh-recheck/security/advisories/new)。普通问题使用 Issues；不要公开上传密钥、认证链接、浏览器状态或真实项目数据。

Supported host scope: DSH 0.2.0-rc.2 with Node.js 24. Recheck uses host file-system policies and stores data locally. A SHA-256 fingerprint is not a signature or a tamper-proof ledger.
